# Playwright Fundamentals with Framework

This repository covers Playwright automation testing fundamentals combined with a structured test framework approach.

## Prerequisites

- Node.js (v16 or higher)
- npm

## Setup

```bash
npm install
npx playwright install
```

## Running Tests

```bash
npx playwright test
```

## Project Structure

- `tests/` - Test files
- `playwright.config.ts` - Playwright configuration
- `package.json` - Dependencies and scripts
